# Tasty Kitchens

A restaurant web application built with React and Vite.

Live demo: https://tasty-kitchens-one.vercel.app

## Features
- Login page with authentication
- Protected routes: only logged-in users can open the home, restaurant and cart pages
- Home page listing restaurants
- Restaurant details page for each restaurant (dynamic route by restaurant ID)
- Cart page
- Custom "Page Not Found" screen for invalid URLs
- Built with React Router for navigation between pages

## Tech Used
- React, Vite, React Router
- HTML, CSS, JavaScript
- Deployed on Vercel

## Run Locally
1. Clone the repo
2. Run `npm install`
3. Run `npm run dev`
